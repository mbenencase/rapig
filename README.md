# RAPIG

![](https://img.shields.io/badge/Rust-000000?logo=rust&logoColor=white)

Rust API Gateway

![](./assets/RAPIG.png)

## Overview

The project's goal is to provide a production-ready API Gateway written in Rust similar to other tools available.

## Roadmap

- [ ] Structured Logging in JSON Format
- [ ] Distributed Tracing with support for OpenTelemetry
- [ ] Prometheus support
- [ ] Timeout & Deadlines
- [ ] Load Shiedding / Backpressure
- [ ] Graceful Shutdown
- [ ] Secrets Manager
- [ ] Rate Limiter
- [ ] Input Sanitization
- [ ] Container for Production-Ready deployment
- [ ] Health Check
- [ ] Hot Reload
